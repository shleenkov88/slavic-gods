# Славянские боги

Статический сайт: что реально известно об основных славянских богах, и что дописано позже.

Сайт открывается здесь:

https://shleenkov88.github.io/slavic-gods/

Картины — художественные образы, не археологические портреты.

## Как устроен репозиторий

- `index.html` — вся страница (разметка, стили и небольшой скрипт плеера и оглавления в одном файле).
- `img/` — картинки для сайта в `webp`, пропорции 4:5: `имя.webp` (864×1080), `имя-md.webp` (640×800), `имя-sm.webp` (512×640), `имя-th.webp` (384×480, для карточек), `og.jpg` — превью для мессенджеров (1200×630).
- `originals/` — исходные `jpg` без сжатия. На сайте не используются; нужны, чтобы пересобрать или заменить иллюстрации.
- `audio/` — озвучка (`mp3`), по одному файлу на бога плюс `intro.mp3` и `cabinet.mp3`.
- `audio/ambient.mp3` — фоновая музыка (2:30, зацикленная без стыка, около 3,6 МБ, стерео, 192 кбит/с). Включается кнопкой-нотой в левом нижнем углу, по умолчанию выключена и не загружается, пока её не включат. Во время озвучки приглушается.
- `tools/ambient.py` — скрипт, которым музыка синтезирована с нуля (numpy: низкий медленный гул на основе ре, тёмный шум, реверберация; без ударных и мелодии).
- `tools/encode_ambient.py` — кодирует синтез в mp3 так, чтобы на стыке петли не было щелчка.
- `fonts/` — шрифты Ruslan Display и Philosopher (кириллица и латиница, `woff2`, лицензия SIL OFL).
- `tools/build_map.py` — собирает подложку карты источников (береговые линии, озёра, реки) из данных Natural Earth (общественное достояние, https://github.com/nvkelso/natural-earth-vector, ne_10m_land / ne_10m_lakes / ne_10m_rivers_lake_centerlines) в упрощённые SVG-path, которые вставлены в `index.html` (раздел `#map`). Берега современные; в IX–XII веках они местами были иными.
- `favicon.svg`, `apple-touch-icon.png` — значки сайта.

## Музыка

Музыку синтезировал сам автор сайта: никаких записей, семплов и мелодий из игр или чужих произведений в ней нет. Всё сгенерировано кодом из `tools/ambient.py` (низкий дрон в ре, длина петли ровно 150 с, все тона и модуляции с целым числом периодов). Это современный фон, а не древний гимн. Чтобы пересобрать: `python3 tools/ambient.py ambient.wav`, затем `python3 tools/encode_ambient.py ambient.wav audio/ambient.mp3` (CBR 192 кбит/с, 44,1 кГц, стерео).

## Как обновлять

Сайт публикуется через GitHub Pages из ветки `main`: после `git push` новая версия появляется через 1–2 минуты.

- Текст: правьте `index.html`. Тексты расширены (октябрь 2026): у каждого бога сразу видно вступление, ниже три раскрывающихся блока: «Что в источниках», «Что дописали позже» и «Откуда это знаем». На телефоне блоки свёрнуты, на компьютере открыты все, кроме «Откуда это знаем». Пометки `источник`, `гипотеза`, `выдумка` внутри текста — это `<span class="tg t-s|t-h|t-f">`. Общие разделы расширены тоже: вступление, «Как читать», «Киевский холм», «Поморье и Рюген», «Кого часто называют богами зря», «Опора» со ссылками.
- Правки октября 2026 (ТЗ «Правки сайта»): ссылки на jassa.org (отвечали 406) заменены латинскими текстами Саксона (Викитека), Титмара и Гельмольда (MGH); утверждения «по пересказам» либо сверены с латынью и подписаны, либо убраны; первая фраза Перуна сужена; добавлены короткие карточки без картинок и без озвучки (Троян, Сварожич Ретры, Яровит, Ругевит/Поревит/Поренут, Прове/Подага/Жива), раздел «После крещения, находки, сроки» (после крещения, вещи без подписи, сроки и места, словарь) и записи Белобог, Коловрат, славянские руны в блоке выдумок. Карточка без картинки — это `<article class="god nopic">` без `<img>` и `<audio>`; в меню (`#toc`) у неё ссылка с классом `g`.
- Новая иллюстрация: положите исходник в `originals/имя.jpg` и сделайте четыре файла `webp` (например, через Pillow: полный размер 864 px, `-md` 640 px, `-sm` 512 px, `-th` 384 px; пропорции 4:5). Размеры `width`/`height` в `<img>` должны совпадать с пропорциями файла.
- Озвучка: замените `audio/имя.mp3`. Плеер подключается автоматически к каждому `<audio data-title="...">`.
- Если меняете картинку, которая уже опубликована, добавьте к имени в разметке `?v=2`, чтобы браузеры не показывали старую.
